COPILOT AUTOFIX

From explanation to pull request

For eligible CodeQL findings, Copilot Autofix combines the rule, data-flow path, and surrounding source to propose a focused fix. The developer reviews the explanation and diff, edits if needed, and opens a pull request. CodeQL and the quality workflow then validate the change.
